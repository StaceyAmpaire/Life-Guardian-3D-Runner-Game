# Life Guardian🌿



Life Guardian is an educational endless runner game developed in Unity to raise awareness about diabetes prevention and management.



Players protect the sacred Baobab Tree by making healthy food and activity choices while earning Healing Dew and unlocking achievements.



---



## Features



- Prevention and Management paths

- Food Run and Activity Run levels

- Avatar selection

- Healing Dew reward system

- Achievement system

- Dynamic Tree Life system

- Educational messages and tutorials

- Android support



---
