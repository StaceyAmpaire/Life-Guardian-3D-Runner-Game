# Life Guardian 🌿



Life Guardian is an educational endless runner game developed in Unity to promote awareness of Type 2 diabetes prevention and healthy lifestyle choices through interactive gameplay.



Players protect the Baobab Tree by making healthy food and activity choices, earning Healing Dew, collecting boosters, and unlocking achievements as they progress through the game.



---



##  Features 



- Prevention and Management game modes

- Food Run and Activity Run levels

- Avatar selection

- Healing Dew reward system

- Achievement system

- Dynamic Tree Life system

- Educational health tips and warning messages

- Collectible boosters

- Interactive tutorials

- Offline gameplay

- Android support

## Gameplay Overview 



###  Prevention Path 



Players run through the environment collecting healthy foods and completing healthy activities while avoiding unhealthy choices. Healthy decisions increase *Tree Life, earn **Healing Dew*, and unlock achievements.



###  Management Path 



Players guide the avatar by making healthy lifestyle decisions. Each decision affects the avatar's health and teaches players about diabetes prevention through educational feedback.



###  Tree Life 



Tree Life represents the player's overall health. Healthy decisions help the Baobab Tree flourish, while unhealthy choices reduce its vitality.



###  Healing Dew 



Healing Dew is earned through healthy gameplay and is used for progression, unlocking achievements, and accessing additional content.



###  Boosters 



Special boosters appear during gameplay to assist the player:



-  *Heart Booster* restores Tree Life. 

-  *Shield Booster* protects the player from one obstacle collision. 

-  *Lightning Booster* temporarily increases running speed.
